# 🚩 Navratri Special • Day 3: Maa Chandraghanta Python Sketch

A Python-based digital art script celebrating **Day 3 of Navratri** dedicated to **Maa Chandraghanta**. This project renders an intricate black & white line sketch with her iconic 10 arms, traditional astras, and her vahana (tiger).

---

## 📌 Prerequisites & Installation

Make sure you have Python installed on your system. Run the following command in your terminal to install the necessary libraries:

pip install opencv-python numpy

---

## 🚀 How to Run

1. Clone the repository:
```
git clone https://github.com/Gracyclub/Day-3-mata-python-sketch.git
```

3. Navigate to the project folder:
```
cd Day-3-mata-python-sketch
```

5. Run the script:
```
python main.py
```
